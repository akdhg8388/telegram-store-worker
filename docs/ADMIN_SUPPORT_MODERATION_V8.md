# V8 — الشحن والدعم والحظر

## طلبات الشحن

- واجهة العميل: رسالة مراجعة مختصرة دون تفاصيل الإدارة. الطلب ينشأ في D1 بعد إرسال الإثبات وتأكيده.
- لوحة المدير > معالجة طلبات الشحن: قائمة عملاء مع الطلبات المعلقة. اختر العميل لرؤية رقم الطلب، الاسم، المعرف، الوقت بتوقيت بغداد، الوسيلة، المبلغ، رقم الحوالة، والصورة.
- زر «مراجعة القبول»: يعرض اعتماد المبلغ المطلوب أو خيار تعديل مبلغ الإيداع الحقيقي بالدينار العراقي، بحد أقصى المبلغ الأصلي. لا يتم الخصم أو الإضافة إلا بعد التأكيد النهائي.
- يتم حفظ `amount_iqd` كمبلغ مطلوب، و`credited_amount_iqd` كمبلغ أُضيف فعلياً. التحديث إلى `approved` وتسجيل `wallet_ledger` في عملية D1 batch مشروطة، ويمنع `source_key` الفريد التكرار.
- بعد القرار تزال أزرار إشعار المدير الأصلي متى سمحت واجهة تيليجرام بذلك. تُعرض الطلبات المعالجة في قائمة مستقلة.
- جميع الأوقات محفوظة في D1 بصيغة UTC وتُعرض بتوقيت `Asia/Baghdad`.

## الدعم

- المستخدم يفتح /support ويكتب رسائل أو يرسل صوراً أو مقاطع فيديو (file_id + الوصف).
- المدير > رسائل الدعم: يختار المستخدم بالاسم أو المعرف الرقمي، يرى آخر الرسائل والتوقيت، يعرض الوسائط، ويستطيع الرد نصاً أو بصورة أو فيديو.
- لا يُرسل رد للعميل ولا يُحفظ كمُرسل إلا بعد تأكيد استلامه من Telegram Bot API.
- الحذف من سجل الدعم مستقل عن الحذف من تيليجرام. للحذف من الطرفين يحاول النظام إزالة نسخ الرسائل المعروفة من حساب العميل وحساب المدير، وبحد أقصى 20 رسالة في الدفعة. تيليجرام يفرض حد 48 ساعة وشروط الصلاحيات؛ **لا يوجد ضمان لحذف جميع النسخ القديمة أو التي لا نملك معرّفها**. تعرض الواجهة العدد المؤكد والجزئي والمتعذر دون ادعاء حذف كامل.

## الحظر والتعليق

- المدير > إدارة المستخدمين: حظر دائم بسبب اختياري أو تعليق 1، 6، 24، 72، 168، 720 ساعة أو مدة مخصصة حتى 8760 ساعة، مع تأكيد قبل التنفيذ.
- فحص الحظر يسبق جميع الأوامر وأزرار المستخدم، ويمنع التفاعل حتى انتهاء التعليق. لا يمكن حظر حساب المدير.
- يتم حفظ التاريخ والسبب. عند انتهاء المدة ينتهي التعليق آلياً في أول تفاعل، دون حذف أرصدة المحفظة أو الطلبات.
- الدفع الناجح الذي يصل متأخراً يعالج محاسبياً حتى لو كان المستخدم محظوراً، كي لا تُفقد أموال العميل.

## ما لا يفعله التحديث

- لا يعدل أرصدة الإنتاج حتى يعتمد المدير شحناً بعينه.
- لا ينشئ بيانات أو مستخدمين تجريبيين في الإنتاج.
- لا يجعل المحفظة وسيلة بديلة عن Telegram Stars لشراء الخدمات الرقمية داخل تيليجرام.
- لا ينشر تلقائياً؛ التشغيل يتم يدوياً من GitHub Actions.
