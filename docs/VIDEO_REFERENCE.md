# ملخص الفيديو المرجعي (نسخة المتجر الأصلية)

المدة التقريبية: 02:41. التوثيق التالي مستخلص من مراجعة الفيديو في المحادثة؛ لا يعني أن كل المزايا مفعلة في النسخة الحالية.

## عناصر واجهة ظهرت في الفيديو

1. قائمة رئيسية ذات أزرار داخل رسائل Telegram؛ منتجات مميزة، المتجر، شحن الرصيد، الملف الشخصي، الإحالات، اللغة، الدعم وقناة الأخبار وAPI Reseller.
2. ملف المستخدم: الاسم، معرف Telegram، الرصيد، عدد الإحالات والمشتريات.
3. شاشة شحن: اختيارات مبلغ ثابت ومخصص، ثم وسائل دفع.
4. تصنيفات متجر بأزرار متجاورة، بحث وجميع المنتجات.
5. منتج: اسم ووصف طويل، مدة، سعر، مخزون، اختيار كمية، شراء ومفضلة.
6. حالة عدم كفاية الرصيد تُظهر توجيهاً للشحن.
7. أقسام الطلبات، سجل العمليات، المفضلة والإحالة ورابط الدعوة.
8. شاشة اللغات وتفضيل لغة الواجهة.

## ملاحظات دقة العرض

- غالبية الشاشات عبارة عن رسائل وأزرار Telegram Inline، وليست Mini App.
- بعض الألوان ضمن تطبيق Telegram، والخلفية المحيطة ليست جزءاً من كود البوت.
- مقاسات وألوان Inline buttons غير قابلة للتحكم الحر باستخدام CSS في bot chat العادي.
- يجب تجنب نسخ الاسم التجاري أو شعارات صاحب البوت المرجعي دون إذن.

## مقارنة النسخة الأولى

منفذ: القوائم الأساسية، البحث، صفحات المنتجات، ملف المستخدم، المفضلة، سجل العمليات والطلبات، الإحالة (إحصائيات فقط)، الشحن اليدوي المنفصل، الموافقة على الطلب والدفع الرسمي.

غير مكتمل: تطابق جميع النصوص وتخطيطات الأزرار وزمن تعديل الرسائل مع الفيديو، اللغة المتعددة، كمية الشراء، نسب مكافآت الإحالة وحساباتها، وميزات API Reseller.
